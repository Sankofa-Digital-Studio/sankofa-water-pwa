# Contributing

Start with the [README](README.md) for local setup and verification. The app covers telemetry, geospatial triage and field repair evidence. Contributions to documentation, accessibility, tests and reproducible bugs are welcome.

## Issues

Use the [issue chooser](https://github.com/Sankofa-Digital-Studio/sankofa-water-pwa/issues/new/choose). Check existing issues first. Include the affected workflow, what you expected and what you observed. Use synthetic readings and redact site coordinates, repair photos, phone numbers and credentials. Route security issues through the [security policy](SECURITY.md).

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep the change focused. Describe the user impact and update related docs when behaviour changes.
3. Run the relevant checks from the [README](README.md#verification). Include the results and any known blockers in the PR.
4. Open a pull request against `main`. Link the issue when one exists and include screenshots for visible changes.

Use an isolated development project for database changes. For changes to field workflows, describe device permissions, connectivity and the evidence used to verify the result.

Participation follows the [code of conduct](CODE_OF_CONDUCT.md).
