# Security Policy

Security reports apply to the current `main` branch. The project has no supported release branches.

Use [GitHub private vulnerability reporting](https://github.com/Sankofa-Digital-Studio/sankofa-water-pwa/security/advisories/new). Include the affected commit, the affected component, the potential impact and enough detail to reproduce the issue safely using synthetic data. Keep credentials, municipal records and precise infrastructure locations out of the report unless maintainers arrange a secure way to receive them.

Keep vulnerability details out of public issues and pull requests while maintainers investigate. Test only on systems you are authorised to use. For routine bugs, use the [issue chooser](https://github.com/Sankofa-Digital-Studio/sankofa-water-pwa/issues/new/choose).
