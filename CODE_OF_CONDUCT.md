# Code of Conduct

We welcome contributors and readers across experience levels, backgrounds and identities. This code applies to project issues, pull requests and other spaces maintained for the project.

Discuss the work respectfully. Give specific feedback, make space for questions and handle disagreement without personal attacks. Harassment, discriminatory language, threats and sharing another person’s private information without permission are unacceptable.

Use GitHub’s **Report content** controls for harassment, threats or other abuse. If the report involves a project maintainer, use [GitHub Support’s reporting channel](https://support.github.com/contact/report-abuse). Share reports privately and include links or a short description of the conduct.

Project maintainers may edit or remove harmful content, limit a participant’s access or refer a report to GitHub. Maintainers should minimise the information they share about a report and keep the reporter’s identity private where practicable.
