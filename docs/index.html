Sankofa Digital Matjhabeng Water PWA

Next.js 15 App Router Supabase SSR Vercel (jnb1) PWA

Overview

The Sankofa Water PWA provides municipal water managers and on-the-ground technicians in Matjhabeng Local Municipality with real-time insight into reservoir pressure levels, flow telemetry, anomaly alarms, and automated WhatsApp alert dispatching.

Core Architecture

  • Frontend: Next.js 15 (App Router, React 19) with Tailwind CSS custom palette (slate-950, cyan, emerald, amber, rose).
  • Data & Auth: Supabase PostgreSQL with SSR cookies session refresh and Row Level Security (RLS).
  • Telemetry Ingest: ChirpStack Webhooks HMAC authenticated on Edge Functions.
  • Field Alerts: Meta WhatsApp Cloud API webhooks and alert dispatch.
  • Latency: Edge function routing pinned to Johannesburg jnb1 region in Vercel.

Quick Commands

# Install dependencies
npm install

# Run local development server
npm run dev

# Run unit tests
npm test

# Run E2E tests
npm run test:e2e
